Choose a mode · Step 2 of 2
Mode for 随笔 — one managed domain, one chain style:
Independent 默认
Direct notes and managed subfolders mix in one ordering. Each managed subfolder keeps its own chain. Best for loosely related notes.
Series
One chain across the whole subtree; subfolders become path labels only. Best for tutorials and serials.
Creates 目录.md with is-index: true and a plugin-owned marked block. Recognition is by the marker, not the file name — you can rename the file later. Mode is stored in the index page’s frontmatter and can be switched any time.
