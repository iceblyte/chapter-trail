Chapter Trail

Folder ordering, index pages and series navigation · v1.0.0 · MIT · no telemetry
Index file name
Used when creating new index pages. Recognition is by the is-index marker, not the file name — existing pages are never renamed. Preset suggestion: index. Changing this marks affected domains “Index outdated”.
Date display on index entries
Reads each note’s created / updated property (ISO date/datetime or Obsidian date format). Entries without a parsable date simply show no date; subfolder entries never show one.
Write prev / next navigation
Off: nothing is ever written into your notes — the jump commands (previous / next / open index) still work. Turning on asks for confirmation, then writes collapsible callouts wrapped in removable markers.
