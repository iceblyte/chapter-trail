Chapter Trail · HTML UI 原型集

Obsidian 插件 chapter-trail 的三件一体能力 —— 文件夹级自定义排序、自动维护的索引页（MOC）、静态可发布的系列导航 —— 的全套高保真界面原型。依据 PRD v1.3 与方案设计文档 v1.1；管理面板为 MVP 核心 UI（React 19 实现的对应物）。界面文案为英文（v1 仅英文 UI），示例笔记内容为中文。所有页面支持浅色 / 深色主题切换（右上角）。

01
管理面板总览

Obsidian 壳 + 右侧边栏面板：VaultSummary、遗留 order 黄条、Series / Independent 域卡片。可右键移动条目、重建索引、停止管理。
02
域卡片状态大全

红（断链 / 结构冲突）、黄（索引过期 / 间隙过密 / 平手）、蓝（待排序）六种卡片形态与图例。
03
拖拽重排交互

脚本化演示两阶段：普通拖拽单文件落位（中点插入）；过密间隙自动重排后落位。含边缘自动滚动与键盘降级。
04
开始管理流程

选文件夹 → 选模式（Independent / Series）两步弹窗，明示「将创建目录.md」后果；成功后卡片入列。
05
确认弹窗合集

重建确认、开启注入确认、同名采纳三选一、嵌套冲突三选一、停止管理、全部清除三步向导（逐域确认）。
06
插件设置页

索引文件名、日期显示方式、「写入上下篇导航」开关（默认关，开关即注入唯一闸门，开关联动确认框）。
07
批量写入进度

25 篇/块、块间让出主线程、可取消、失败跳过汇总；右下角 Notice 即真实呈现位置，附事件日志。
08
成品效果预览

索引页阅读视图、注入 callout 阅读态（可折叠）、Quartz 发布效果，以及与动态代码块方案的对照。

演示数据设定（全套页面共用）

用户画像：教程 / 连载作者，约 1000 篇笔记、git 同步、发布到 Quartz。
· Blogs/Quartz 建站教程 — Series 域，5 篇 + 「进阶篇」子树，注入已开启；
· 读书笔记/卡片盒笔记法 — Independent 域，直系文件与受管子文件夹混排，注入关闭；
· 随笔/数字花园周记 — Series 域，小型域；
· Vault 级黄条：已解散域「旧项目/周刊」遗留 12 个 order 字段。

设计基线

· 融入 Obsidian：仅用主题 CSS 变量（--background-primary、--interactive-accent 等）+ ct- 前缀类名，跟随用户主题与强调色；
· 状态三色：红 = 必须处理（断链 / 冲突），黄 = 建议处理（过期 / 重排 / 平手 / 遗留），蓝 = 待排序提示；
· 显式且可逆：批量写入前确认并显示数量，进度可取消，全部清除走逐域确认；
· 条目行 32px 等高（虚拟化前提），order 等宽字体右对齐，日期受设置约束。

本原型为静态 HTML / CSS / JS，不依赖外部资源；样式仅作布局与状态演示，实现阶段以 Obsidian 宿主主题变量为准。
